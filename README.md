# 🎬 Movie Recommendation System

> Discover movies you’ll love using AI 🍿

---

## 🌍 Problem Statement

With thousands of movies available, users struggle to find relevant content.

Traditional recommendation:
- ❌ Not personalized  
- ❌ Limited discovery  

This project solves it using **content-based filtering**.

---

## 🎯 Objective

- Recommend movies based on user preferences
- Improve content discovery experience

---

## ⚙️ How It Works

### 📊 1. Data Processing
- 5000+ movie dataset

### 🧠 2. Feature Extraction
- TF-IDF vectorization on movie metadata

### 🔍 3. Similarity Calculation
- Cosine similarity matrix

### 🌐 4. Deployment
- Streamlit interactive UI

---

## 🔑 Key Features

- 🎯 89% recommendation precision
- ⚡ Instant recommendations
- 🎥 Clean UI interface

---

## 🛠️ Tech Stack

- Python, pandas
- scikit-learn
- Streamlit
